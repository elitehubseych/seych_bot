# Шрифты для чеков Elite Bank

Шрифты уже включены в проект и поддерживают кириллицу:

- Tektur-Medium.ttf — заголовок "Elite Bank" и суммы (жирный, футуристичный)
- Jura-Medium.ttf — основной текст
- Jura-Light.ttf — подписи/лейблы (приглушённые)

Оба шрифта — Google Fonts, лицензия SIL Open Font License (см. *-OFL.txt рядом).
Свободно используются в коммерческих проектах, атрибуция в самом продукте не требуется.

Если захочешь заменить на свои — просто положи .ttf сюда и поменяй имена файлов
в константах FONT_BOLD_FILE / FONT_REGULAR_FILE / FONT_LIGHT_FILE в utils/receipt.py.
Важно: не все шрифты с Google Fonts поддерживают кириллицу — если текст на чеке
вдруг превратится в квадратики, значит у выбранного шрифта нет русских букв.
